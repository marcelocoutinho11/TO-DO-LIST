# Contributing Guide

Thanks for your interest in contributing.

## Development Setup
1. Clone the repo.
2. Open in VS Code.
3. Run with Live Server using `public/index.html`.

## Branch Strategy
- `main`: stable branch
- Feature branches: `feature/<short-name>`
- Fix branches: `fix/<short-name>`

## Commit Style
Use small, clear commits with action-oriented messages, for example:
- `Improve mobile sidebar behavior`
- `Add calendar task chips`
- `Fix music dock visibility on mobile`

## Pull Request Checklist
- Keep PR focused on one concern.
- Update docs if behavior changes.
- Confirm no secrets are included.
- Verify app behavior on desktop and mobile.

## Code Style
- Keep changes minimal and targeted.
- Preserve existing naming and file structure.
- Prefer readable code over clever code.

## Reporting Bugs
When creating an issue, include:
- Expected behavior
- Actual behavior
- Reproduction steps
- Browser/device details
- Screenshots if relevant
