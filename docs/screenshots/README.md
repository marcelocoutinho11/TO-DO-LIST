# Screenshots

Add portfolio screenshots here using these exact filenames:

- `home.png`
- `calendar.png`
- `mobile.png`

Recommended capture tips:

1. Use your browser at 100% zoom.
2. Keep consistent window size for desktop shots.
3. For mobile, use DevTools device emulation (e.g., iPhone 12/13).
4. Avoid showing personal data in tasks/profile names.

After adding images, commit and push:

```bash
git add docs/screenshots
git commit -m "Add real README screenshots"
git push
```
