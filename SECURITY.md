# Security Policy

## Supported Versions
This is an active learning/portfolio project. Security fixes are applied on the latest `main` branch.

## Reporting a Vulnerability
If you discover a vulnerability:
1. Do not open a public issue with exploit details.
2. Contact the maintainer directly through GitHub profile contact options.
3. Include:
   - Affected feature/file
   - Steps to reproduce
   - Potential impact
   - Suggested fix (if available)

## Response Expectations
- Initial acknowledgement: within 7 days
- Triage and fix timeline: best effort based on severity and project availability

## Security Best Practices for Contributors
- Never commit secrets (API keys, tokens, passwords)
- Avoid introducing unsafe DOM injection patterns
- Validate and sanitize user-controlled input
- Keep dependencies and tooling updated
